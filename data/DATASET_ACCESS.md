# ProAct Dataset Access

ProAct dataset access is intended for individually approved researchers conducting non-commercial scientific research under the [Data Use Agreement](DATA_USE_AGREEMENT.md). The dataset is separate from the repository's Apache 2.0-licensed code.

**Current status:** the online application endpoint and Hugging Face dataset repository are being configured. There is no live download link in this document. The final release contents will be listed with the dataset; access should not be taken to imply that every task or asset described in the paper is included.

## How access will work

1. Sign in to your own individual Hugging Face account.
2. Follow the dataset link published here when it becomes available and complete the native Hugging Face gated-access application form with your research details and acceptance of all three statements below.
3. Hugging Face sends a real-time notification of the new application to zhuxiaomeng224@gmail.com. The dataset owner reviews the application and, if accepted, grants access to that individual account on Hugging Face. Approval is manual and is not automatic on submission.
4. After approval, download while authenticated with your approved account. If using a download tool, use your own access token and keep it private.

Each researcher needs a separate application and approval, including members of the same lab or project. Do not use a shared account, share tokens, or obtain the files from another applicant. Review time may vary; no approval or turnaround time is guaranteed.

## Apply by email during setup

While the online endpoint is being configured, send the template below to [zhuxiaomeng224@gmail.com](mailto:zhuxiaomeng224@gmail.com?subject=ProAct%20dataset%20access%20request) with the subject **ProAct dataset access request**. Complete every field, read the [Data Use Agreement](DATA_USE_AGREEMENT.md), and mark each acceptance statement with `[x]` if you agree.

An email application does not itself grant access or enable downloads. Approved applicants will still need individual access on Hugging Face when the dataset repository is ready.

```text
Subject: ProAct dataset access request

Full name:
Institution / organization:
Institutional email:
Role / position:
Hugging Face username:
Hugging Face profile URL:
Research purpose (research question, planned use, and expected outputs):

I have read the ProAct Data Use Agreement and accept its terms:

[ ] I will use the ProAct dataset only for non-commercial scientific research as described in my application, and will obtain prior written permission for products, commercial services, or other commercial exploitation.
[ ] I will not identify or attempt to identify people in the dataset, link the data to identifying information, contact people depicted in it, or reverse or attempt to reverse privacy transformations.
[ ] I will not redistribute or mirror the dataset, expose restricted content in derived material, bypass access controls, or share credentials or access tokens without prior written permission; each researcher must apply separately.
```

Send access questions, requests for written exceptions, and private reports of privacy concerns to [zhuxiaomeng224@gmail.com](mailto:zhuxiaomeng224@gmail.com).
